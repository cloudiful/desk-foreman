# 已保留任务的显式选定文件导出

[English](execution-environment-task-exports.md) · [原生任务](execution-environment-tasks.zh-CN.md)

应用可以为已保留、且有正向停止证明的原生任务授权一次不可变的 UTF-8 文件选集导出。
导出使用任务原始 Manager 和已停止的候选代次。在任务被显式释放或后继环境变为 ready 后，
该授权仍然有效；导出不改变当前环境、任务状态、工作区占用或 relay 流。

Docker Manager 后端在本地采集选定文件，不调用 Docker CLI 或 socket。其他后端拒绝不支持的采集。
没有自动导出、释放、清理、文件发现、归档或规范项目导入。

## 保留工作区采集

采集要求已有本地任务根目录、匹配的已发布准备日志及持久化停止围栏。按顺序持有环境互斥锁、
持久化环境预约锁和任务锁。后继代次的更高水位不阻止读取已停止的旧任务。采集不恢复种子、
创建目录或重写日志、围栏和历史，也不要求宿主根映射、镜像凭据或服务创建配置。
只允许创建和移除工作区之外的既有预约锁文件。

只检查选定文件及其祖先。原生任务创建的 0755 目录和 0644 文件在属于 Manager 且组或其他用户
不可写时可接受。符号链接、硬链接、特殊文件、选定目录、异主文件和不安全权限均被拒绝。
有界读取前后检查打开句柄的身份、大小和修改时间，选集读取后再次检查受保护根目录身份。
这是可信私有根目录上的检查后打开保护，不是无竞态的 openat 沙箱。

选定叶节点或祖先缺失会记录为 missing；任务、日志或已发布树缺失则是错误。
选定二进制、含 NUL 或超限内容使整个导出失败；不打开未选内容。
Manager 在上传前将序列化 JSON 限制为 16 MiB，包括转义膨胀。只有 204 确认才允许返回摘要；
拒绝或响应丢失会失败，不自动重新采集或重试。

## 应用端点

所有端点都从应用 Bearer 解析属主。请求拒绝未知字段，不接收宿主路径、Manager 配置或凭据。

### 调度

`POST /api/internal/execution-environments/{environment_id}/tasks/{task_id}/export`

```json
{
  "operation_token": "selected-output-1",
  "stop_job_id": "123e4567-e89b-12d3-a456-426614174000",
  "paths": ["README.md", "src/main.rs", "new.txt"]
}
```

任务必须处于 `stopping` 或 `released`，并持有匹配且成功的任务级停止作业。证明必须正向确认
`absent`、`exited` 或 `dead`，同时记录 `preparation_quiescent: true`。环境、应用、任务、
原始 Manager 和候选代次均须与保留证明一致。当前环境代次和 active-task 身份不是导出围栏。

新调度要求原始 Manager 已启用且在线。相同 token、证明、任务和规范选集的重放，即使在
Manager 离线时也返回同一作业。每个任务只有一次选集：不同 token 或改变选集均为冲突，
包括失败或过期后。作业不会改派，也不会自动重试。

### 查看与下载

- `GET .../tasks/{task_id}/export/status` 返回小型描述：`task_id`、`job_id`、
  `stop_job_id`、`state`、`selection_sha256` 和可选 `output_manifest_sha256`。
- `GET .../tasks/{task_id}/export/content` 返回已提交输出；没有成功输出时返回 `409`。

内容携带 `task_id`、`stop_job_id`、两个摘要、带 `path` 和 `content` 的 `files`，以及
`missing_paths`。文件与缺失路径互斥、规范排序，且并集必须恰好等于授权选集。存在但内容为空
的文件不同于缺失路径。新增文件可以被显式选中。

该输出不是完整项目快照。未选中路径既不读取也不表示；后续导入方不得将选集外的省略解释为删除。

## 原始 Manager 上传

`POST /api/internal/runner-managers/{manager_id}/environment-jobs/{job_id}/task-export`

先验证 Manager Bearer，再解析请求体。路径中的 Manager 必须是已认证 Manager，且作业归其
所有。上传使用严格的 `ExportNativeTaskUpload`，将轮询获得的原样 `request` 与 `content`
并列嵌套。轮询请求包含持久化环境属主、任务运行时身份、停止作业、规范路径和选集摘要。

只有尚未过期、已 claimed 的导出作业可以提交新输出。控制面持有新取得的锁，再次验证原始
Manager、任务、头记录、证明、选集和已停止候选代次。控制面校验并规范化输出，然后在同一
事务中写入文件、缺失路径、输出元数据和作业成功状态。失败不会留下部分输出或成功作业。

原始 Manager 对已成功输出的完全相同上传是只读 `204`；改变终态内容返回 `409`。没有匹配的
已提交输出时，普通 job-result 成功确认不能成功。作业结果 JSON 仅含小型 `ExportNativeTaskResult`
身份、摘要、计数和字节总量，绝不包含文件内容。普通失败可以使导出终止而不产生输出；过期将
导出标记为 `uncertain`，不改变后继环境生命周期。

## 上限与状态码

| 限制 | 值 |
| --- | --- |
| 选中路径 | 1–4096 |
| 路径，UTF-8 字节 | 512 |
| 单个文件内容，UTF-8 字节 | 1 MiB |
| 内容总量，UTF-8 字节 | 8 MiB |
| JSON 解析前的请求体 | 16 MiB |

路径使用[种子路径规则](execution-environment-tasks.zh-CN.md#路径规则)：规范化相对 POSIX
文件路径，拒绝 `.git`、绝对或遍历分量、反斜杠、控制字符、重复和祖先冲突。内容必须是无 NUL
的 UTF-8 文本。传输上限同时检查声明长度和实际请求体，包括 chunked 请求体。

| 状态码 | 含义 |
| --- | --- |
| 200 | 新调度或重放意图、描述或已提交内容。 |
| 204 | Manager 输出已提交，或完全相同的终态上传/结果重放。 |
| 400 | 畸形或未知字段、无效路径/内容形态或无效 token。 |
| 401 | Bearer 缺失或无效。 |
| 404 | 外来或不存在的应用任务/导出、Manager 路径身份或作业。 |
| 409 | 证明、选集、摘要、精确输出集合、claim 或不可变重放冲突；输出未就绪。 |
| 413 | 请求体、条目数、单文件内容或内容总量超限。 |
| 503 | 新意图所需的原始 Manager 不可用。 |

## 摘要编码

选集 SHA-256 使用 `df-native-task-export-selection-v1` 后跟 NUL，再按路径字典序依次加入
每个路径的 u64 大端字节长度和 UTF-8 字节。

输出 SHA-256 使用 `df-native-task-export-v1` 后跟 NUL，再按选中路径字典序依次加入路径的
u64 大端字节长度和字节。存在的文件随后加入字节 `1`、内容的 u64 大端字节长度和内容字节；
缺失路径加入字节 `0`。两个摘要均为小写十六进制，并使用共享的生产者/消费者校验器。

输出摘要仅表示选集内容，不等于原始输入种子摘要，也不等于完整工作区摘要。
